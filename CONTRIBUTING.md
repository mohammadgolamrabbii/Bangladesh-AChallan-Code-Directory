# Contributing to Bangladesh A-Challan Code Directory

Thank you for helping improve **Bangladesh A-Challan Code Directory**, architected by **[Mohammad Golamrabbii (মোহাম্মদ গোলাম রাব্বী)](https://github.com/mohammadgolamrabbii)**.

## How to Contribute
1. **Fork the Repo**: Fork to your GitHub account.
2. **Clone**:
   ```bash
   git clone https://github.com/<your-username>/Bangladesh-AChallan-Code-Directory.git
   cd Bangladesh-AChallan-Code-Directory
   ```
3. **Verify Tests**:
   ```bash
   npm test
   ```
4. **Submit a Pull Request**: Submit your PR targeting `main`.

## Code & Data Standards
- All economic codes must adhere to the 13/14-digit iBAS++ budgeting classification standard.
- Fee structures must correspond to gazetted government statutory regulatory orders (SROs).
